\problemname{Submarine Stress}

A submarine engineer is working on a strip of a new composite material for the hull of a deep sea vessel. They are scanning the strip of material for points of stress. This new material can handle slight variation in stress, but if the difference between the highest and lowest stress points grows too large, it shatters. 

Furthermore, larger continuous panels become more brittle the longer they are. As the panel hits specific length thresholds, it requires stricter levels of stress tolerance.

\section*{Input}
The input consists of four lines[cite: 30]:

The first line contains two integers: $n$ ($1 \le n \le 10^5$), the length of the stress readings array, and $k$ ($1 \le k \le 10^5$), the length of the levels array.

The second line contains a single integer $L$ ($1 \le L \le 10^9$), representing the maximum stress tolerance limit.

The third line contains $n$ integers representing the stress readings at each point. Each reading is between $1$ and $10^9$.

The fourth line contains $k$ integers representing the length thresholds in strictly increasing order. Each threshold is between $1$ and $n$.

\section*{Output}
Output a single integer representing the length of the longest contiguous panel (subarray) that satisfies the condition[cite: 30]:
\[ (\text{max\_stress} - \text{min\_stress}) \times \text{multiplier} \le L \]

The multiplier starts at $1$. For each threshold in the levels array that the panel's length strictly exceeds, the multiplier increments by $1$.
